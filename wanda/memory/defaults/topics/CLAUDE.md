# topics/

Ongoing projects, issues and events: things with a beginning, developments, and an end. The file name is a short slug of the issue (`hoa-board-election.md`), not of one development in it.

Before minting a topic, search: an update to an existing issue is a new claim on its note, not a new note. Link the people and orgs involved with `about::` edges so the graph shows who is in it.

When a topic ends, its claims stay; add a closing claim rather than deleting.
