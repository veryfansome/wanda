# wanda's memory vault

Open this folder in Obsidian. Everything here is plain markdown and git-tracked; wanda commits on a schedule and never deletes a note (retired notes move to `retired/`).

- Edit anything in `people/`, `orgs/`, `topics/`, `prefs/`, `open/`. A changed claim line is treated as your word and pinned; text under `## Notes` is never touched.
- `belt/` is machine-owned and regenerated hourly. To veto something there, use `wanda memory forget`.
- Each directory's `CLAUDE.md` is wanda's write-spec for that directory: what belongs there and how it is named. wanda edits these from your stated preferences and reports every change in the digest.
- `wanda memory --help` lists what the CLI can do; `git log` in this folder shows what changed and when.
