# orgs/

Companies, schools, boards, clubs and the mailing lists they run. The file name is the slug of the common name, or the registrable domain while that is all that is known (`sunnybrook.example.md`).

`ids:` lists `mailto:` role addresses, `dom:` domains and `list:` List-Ids that mean "this organisation is speaking". People who write on an org's behalf get their own person note with an `about::` edge here.

One org, one note — do not mint `rla` next to `riverside-language-academy`; add an alias instead.
